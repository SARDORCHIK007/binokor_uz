# To‘xtagan ish

## Telegram jonli xabar

Nima: bot kirish kodini va buyurtma xabarini haqiqiy chatga yubora olmaydi.

Nega: `.env` dagi `BOT_TOKEN` bo‘sh. Maxfiy fayl o‘zgartirilmadi.

Nima qilindi: `/start` va telefonni bog‘lash kodi yozilgan. Token bor bo‘lsa API `sendMessage` chaqiradi. Token yo‘qligi uchun lokal rejimda kod sahifada qoladi. Qayta urinish token siz yordam bermaydi.
